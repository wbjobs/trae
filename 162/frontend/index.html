📈 订单时序图

sequenceDiagram
    participant 客户端
    participant gRPC_Server
    participant Temporal_Workflow
    participant Activity_Inventory
    participant Activity_Payment
    participant Activity_Shipping

    Note over 客户端,Temporal_Workflow: === 订单创建阶段 ===
    客户端->>gRPC_Server: CreateOrder(user_id, items)
    gRPC_Server->>Temporal_Workflow: Start Workflow
    Temporal_Workflow->>Activity_Inventory: ReserveInventory()
    Activity_Inventory-->>Temporal_Workflow: OK (库存已锁定)
    Temporal_Workflow-->>gRPC_Server: Workflow Running
    gRPC_Server-->>客户端: Order { state: PENDING_PAYMENT }

    Note over 客户端,Temporal_Workflow: === 等待支付 (30分钟超时) ===
    alt 支付成功
        客户端->>gRPC_Server: TriggerEvent(PAY_SUCCESS)
        gRPC_Server->>Temporal_Workflow: Signal Payment
        Temporal_Workflow->>Activity_Payment: ProcessPayment()
        Activity_Payment-->>Temporal_Workflow: Payment OK
    else 支付超时
        Temporal_Workflow->>Temporal_Workflow: Timer (30min)
        Temporal_Workflow->>Activity_Inventory: RollbackInventory()
        Temporal_Workflow->>Activity_Inventory: CancelOrder()
        Temporal_Workflow-->>gRPC_Server: CANCELLED
    else 支付失败
        客户端->>gRPC_Server: TriggerEvent(PAY_FAIL)
        gRPC_Server->>Temporal_Workflow: Signal Payment(Fail)
        Temporal_Workflow->>Activity_Inventory: RollbackInventory()
        Temporal_Workflow-->>gRPC_Server: CANCELLED
    end

    Note over 客户端,Temporal_Workflow: === 发货与完成 ===
    Temporal_Workflow->>Activity_Shipping: ShipOrder()
    Activity_Shipping-->>Temporal_Workflow: Shipped (tracking_id)
    Temporal_Workflow->>Activity_Shipping: ConfirmReceipt()
    Temporal_Workflow-->>gRPC_Server: COMPLETED
    gRPC_Server-->>客户端: Final State: COMPLETED
