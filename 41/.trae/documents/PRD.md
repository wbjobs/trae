# 低代码表单平台 - 产品需求文档

## 1. 产品概述

基于 React + Node.js 的低代码表单平台，提供拖拽式表单编辑器和规则引擎，支持条件触发和联动动作。

## 2. 功能需求

### 2.1 表单编辑器

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 拖拽式组件库 | 支持输入框、下拉选择、日期选择等基础组件 | 高 |
| 组件属性配置 | 配置组件的标签、占位符、必填项等属性 | 高 |
| 表单预览 | 实时预览表单效果 | 中 |
| 表单保存/加载 | CRUD操作管理表单配置 | 高 |

### 2.2 规则引擎

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 条件配置 | 支持字段值比较、逻辑运算符(>、<、==、!=) | 高 |
| 动作配置 | 支持隐藏/显示组件、启用/禁用组件 | 高 |
| 嵌套逻辑 | 支持 AND/OR 嵌套组合条件 | 高 |
| 规则预览 | 实时预览规则效果 | 中 |

### 2.3 数据管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 用户提交数据存储 | 保存用户填写的表单数据 | 高 |
| 表单列表 | 展示所有表单配置 | 高 |
| 数据查询 | 查询用户提交的表单数据 | 中 |

## 3. 规则引擎示例

### 示例场景
- **场景1**: 当输入框值 > 100 时，隐藏下拉组件并禁用提交按钮
- **场景2**: 当下拉选择"其他"时，显示额外输入框

### 规则JSON Schema
```json
{
  "ruleId": "string",
  "formId": "string",
  "name": "string",
  "conditions": {
    "type": "AND|OR",
    "children": [
      {
        "fieldId": "string",
        "operator": ">|<|==|!=",
        "value": "any"
      }
    ]
  },
  "actions": [
    {
      "type": "hide|show|disable|enable",
      "targetFieldId": "string"
    }
  ]
}
```

## 4. 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | React | 18+ |
| 状态管理 | Zustand | 4+ |
| 样式 | Tailwind CSS | 3+ |
| 后端 | Node.js + Express | 20+ |
| 数据库 | SQLite | 3+ |
| 图标 | Lucide React | 0.263+ |

## 5. 用户角色

| 角色 | 权限 |
|------|------|
| 表单管理员 | 创建/编辑/删除表单、配置规则 |
| 普通用户 | 填写表单、查看提交历史 |

## 6. 非功能需求

- 响应式设计，支持移动端
- 表单数据实时验证
- 规则引擎执行效率 < 100ms
