# 三维地质体模型可视化应用

一个基于Web的三维地质体模型可视化应用，支持体素渲染、平面切片、钻井模拟和岩芯柱状图展示。

## 功能特性

- 🌍 **三维地质体渲染**：支持体素模式、表面模式和线框模式
- ✂️ **平面切片工具**：支持X、Y、Z三个轴的任意位置切片，使用自定义着色器实现
- ⛏️ **钻井模拟**：鼠标点击位置创建钻孔，实时显示钻孔路径
- 📊 **岩芯柱状图**：自动生成钻孔穿过的岩层序列
- 📝 **日志导出**：支持导出CSV和TXT格式的钻孔日志
- 🎨 **自定义着色器**：使用GLSL着色器实现体绘制和切片效果

## 技术栈

- **前端**：Three.js + GLSL Shaders + Vite
- **后端**：Node.js + Express
- **数据格式**：VTK (Visualization Toolkit)

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

这将同时启动：
- 后端服务：http://localhost:3001
- 前端开发服务器：http://localhost:5173

### 单独启动服务

只启动后端服务：
```bash
npm run server
```

只启动前端开发服务器：
```bash
npm run client
```

### 构建生产版本

```bash
npm run build
```

## 使用说明

### 显示模式切换

1. **体素模式**：默认模式，显示半透明的地质体
2. **表面模式**：显示不透明的表面渲染
3. **线框模式**：显示网格线框

### 切片操作

1. 点击X轴/ Y轴/ Z轴切片按钮
2. 使用滑块调整切片位置
3. 点击"重置切片"按钮恢复完整视图

### 钻井操作

1. 点击"启用钻井模式"按钮
2. 在三维视图中点击地质体表面任意位置
3. 系统会自动计算钻孔路径并显示岩芯柱状图
4. 点击"导出钻孔日志"保存数据
5. 点击"清除钻孔"移除所有钻孔

### 操作说明

- **鼠标左键拖动**：旋转视角
- **鼠标滚轮**：缩放视图
- **鼠标右键拖动**：平移视图

## API接口

### GET /api/health
检查服务状态

### GET /api/models
获取可用模型列表

### GET /api/model/:id
获取模型数据

### POST /api/drill
计算钻孔路径和岩芯数据

请求体：
```json
{
  "position": { "x": 50, "y": 50 },
  "modelData": { ... }
}
```

### POST /api/export-log
导出钻孔日志

请求体：
```json
{
  "drillData": { ... },
  "format": "csv"  // 或 "txt"
}
```

## 自定义数据

要使用自定义VTK数据，请将数据文件放入`data`目录，并修改`server/index.js`中的模型加载逻辑。
