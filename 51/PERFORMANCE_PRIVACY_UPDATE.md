# 性能优化与隐私模式 - 更新说明

## 更新概述

本次更新包含两个主要功能：
1. **性能优化**：将人脸模糊处理迁移到 WebWorker 中计算，避免主线程阻塞
2. **隐私模式**：新增隐私模式开关，提供更强的隐私保护

---

## 一、性能优化：WebWorker 人脸处理

### 架构改进

**之前的问题：
- 人脸检测和像素化模糊都在主线程执行
- 像素化计算是 CPU 密集型操作，会阻塞 UI 线程
- 导致视频流卡顿，帧率下降

**现在的架构：

```
┌──────────────────────────────────────────────────────────┐
│  主线程 (Main Thread)                           │
│  ┌────────────┐    ┌──────────────────────┐   │
│  │  人脸检测   │ → │  视频帧捕获/渲染     │   │
│  └────────────┘    └──────────┬───────────┘   │
│                                │               │
│                          ImageData             │
│                                ↓               │
└──────────────────────────────────────────────────────────┘
                                 │
                      Transferable Objects
                                 │
┌──────────────────────────────────────────────────────────┐
│  WebWorker (Worker Thread)                       │
│  ┌──────────────────────────────────────────┐   │
│  │  像素化模糊计算                        │   │
│  │  (processPixelation / generateMosaic)     │   │
│  └───────────────────┬──────────────────────┘   │
│                      │                        │
│                处理后的 ImageData            │
│                      │                        │
└──────────────────────────────┼────────────────────────┘
                        │
              Transferable Objects
                        │
┌──────────────────────────────────────────────────────────┐
│  主线程 (Main Thread)                           │
│                      ↓                                  │
│          渲染到 Canvas                           │
└──────────────────────────────────────────────────────────┘
```

### 性能收益

- **主线程负载降低**：像素化计算完全在 WebWorker 中执行
- **帧率提升**：避免了主线程阻塞，视频流更流畅
- **响应性提升**：UI 交互更流畅，滑块调整等操作无延迟
- **可扩展性**：WebWorker 架构便于后续添加更多图像处理功能

### 技术实现

1. **文件**：`js/face-processor.worker.js`
   - `processPixelation()` - 处理人脸区域像素化
   - `generateMosaic()` - 生成全屏动态马赛克

2. **主线程通信**：
   - 使用 `Transferable Objects` 传递 `ImageData`
   - 零拷贝数据传输，避免内存复制
   - 异步回调机制，不阻塞主线程

3. **降级策略**：
   - 浏览器不支持 WebWorker 时自动回退到主线程处理
   - WebWorker 出错时自动回退

## 二、隐私模式

### 功能说明

隐私模式提供极致的隐私保护，启用后：

| 功能 | 正常模式 | 隐私模式 |
|------|---------|----------|
| 音频推流 | ✅ 发送到后端进行语音识别 | ❌ 停止发送，断开 WebSocket |
| 字幕来源 | 后端语音识别结果 | 前端生成随机假字幕 |
| 视频处理 | 仅人脸区域像素化 | 全屏动态马赛克 |
| 人脸检测 | ✅ 执行人脸检测 | ❌ 停止人脸检测 |

### 隐私模式效果

1. **停止音频推流**：
   - 立即停止麦克风音频采集
   - 断开 WebSocket 连接
   - 不再向**任何音频数据发送到后端

2. **随机假字幕**：
   - 前端本地生成技术类随机语句
   - 字幕滚动显示，模拟真实字幕效果
   - 不涉及任何真实语音内容

3. **全屏动态马赛克**：
   - 整个视频画面覆盖动态马赛克
   - 马赛克块大小可配置（默认 25px）
   - 动态偏移效果，增强隐私保护
   - 完全无法识别画面内容

### 用户界面

1. **开关位置**：控制面板新增「🔒 隐私模式」复选框
2. **视觉提示**：启用后右上角显示紫色「🔒 隐私模式已启用」提示条
3. **状态动画**：提示条带有脉冲动画，明确告知当前状态

### 使用场景

- 需要录制敏感会议
- 公共场合演示
- 保护被采访对象隐私
- 测试时避免真实语音被识别

## 四、API 变更

### FaceDetector 新增方法

```javascript
// 应用全屏动态马赛克
await faceDetector.applyFullMosaic(video, canvas, blockSize);

// 销毁 WebWorker
faceDetector.destroy();
```

### FakeSubtitleGenerator API

```javascript
// 创建实例
const generator = new FakeSubtitleGenerator();

// 开始生成假字幕
generator.start((text) => {
    console.log('假字幕:', text);
}, interval);

// 停止生成
generator.stop();
```

### App 新增属性

```javascript
// 检查是否为隐私模式
app.isPrivacyMode;

// 切换隐私模式
await app.togglePrivacyMode(true/false);
```

## 八、注意事项

1. **WebWorker 限制**：
   - 无法访问 DOM
   - 无法直接访问 video 元素
   - 数据通过 postMessage 传递

2. **隐私模式限制**：
   - 启用后无法接收真实语音识别结果
   - 关闭后需要重新连接 WebSocket
   - 假字幕为随机生成，不反映真实内容

3. **性能建议**：
   - 马赛克块越小，计算量越大
   - 建议块大小在 15-35px 之间
   - 性能较低设备可适当增大块大小
