🚀 LZ4 多线程压缩

实验性功能 · Web Worker + SharedArrayBuffer · 分块并行压缩

⚠️ SharedArrayBuffer 要求

使用多线程功能需要设置以下 HTTP 头：

Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp

可以使用以下命令启动支持 COOP/COEP 的服务器：

npx http-server --cors --coop --coep

📋 功能说明

  • 基于 Web Worker 的多线程并行压缩
  • 自动文件分块，各块独立压缩
  • 支持 SharedArrayBuffer 零拷贝传输
  • 输出标准 .lz4 多帧格式
  • 各块包含独立索引，支持随机访问
  • 进度实时显示，可随时取消
